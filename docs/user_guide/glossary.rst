.. _glossary:

===========
Глоссарий
===========

Один термин означает одно понятие во всём тексте и в обоих языках. Таблица фиксирует соответствия русских и английских терминов.

.. list-table::
   :header-rows: 1
   :class: hm-table
   :widths: 26 26 48

   * - Русский термин
     - Английский термин
     - Смысл
   * - расход воды
     - discharge
     - объём воды, проходящий через створ за единицу времени, м³/с
   * - сток
     - runoff, streamflow
     - вода, стекающая с водосбора; в тексте «сток» относится к ряду расходов или к объёму
   * - гидрограф
     - hydrograph
     - график изменения расхода воды во времени
   * - створ
     - gauge, station
     - место измерения расхода на реке
   * - водосбор, бассейн
     - catchment, basin
     - территория, с которой вода стекает к створу
   * - половодье
     - spring flood
     - ежегодное длительное повышение расходов в одну и ту же фазу года
   * - паводок
     - flood (event)
     - кратковременный подъём расходов, не связанный с сезоном
   * - пик
     - flood peak
     - наибольший расход половодья или паводка
   * - межень
     - low flow
     - период наименьших расходов
   * - водный год
     - water year
     - год, который в примерах начинается 1 октября и называется по году окончания
   * - обеспеченность
     - exceedance probability
     - вероятность превышения расхода
   * - кривая обеспеченности
     - flow duration curve
     - расходы, упорядоченные по убыванию
   * - невязка, ошибка
     - residual, error
     - разность модельного и наблюдённого значения
   * - ряд наблюдений
     - observed series, record
     - измеренные значения во времени
   * - модельный ряд
     - simulated series
     - значения, рассчитанные моделью
   * - калибровка
     - calibration
     - подбор параметров модели; термин «валидация» в тексте не используется
   * - верификация
     - verification
     - проверка модели или прогноза на данных, не участвовавших в калибровке
   * - контрольный период
     - verification period
     - период, на котором выполняется верификация
   * - прогноз
     - forecast
     - значение величины, заданное до наблюдения
   * - заблаговременность
     - lead time
     - интервал между выпуском прогноза и прогнозируемым моментом
   * - ансамблевый прогноз
     - ensemble forecast
     - набор прогнозов (членов ансамбля) для одного момента
   * - опорный прогноз
     - reference forecast, benchmark
     - прогноз, с которым сравнивается проверяемый
   * - допустимая погрешность
     - permissible error
     - предел ошибки, внутри которого прогноз считается оправдавшимся
   * - попадание, ложная тревога, пропуск
     - hit, false alarm, miss
     - элементы таблицы сопряжённости прогноза события
   * - метрика
     - metric
     - общий термин для любого показателя качества; названия вроде «критерий Нэша–Сатклиффа» даны по литературе
   * - оценка
     - score
     - значение, выдаваемое оценочной функцией, например оценка Брайера
   * - индекс мастерства
     - skill score
     - относительное улучшение по сравнению с опорным прогнозом
   * - оптимум
     - optimum
     - значение метрики у безошибочной модели
   * - надёжность
     - reliability
     - совпадение прогнозных вероятностей с частотами событий
   * - чёткость
     - sharpness
     - концентрация прогнозных вероятностей у крайних значений
   * - бэкенд
     - backend
     - реализация метрики для одного типа данных: numpy, pandas, polars, xarray
   * - диспетчеризация
     - dispatch
     - выбор бэкенда по типу входа
   * - ядро
     - kernel
     - функция расчёта на numpy-массивах, общая для всех бэкендов
   * - ось
     - axis
     - измерение массива, вдоль которого считается метрика
   * - пропуск (в данных)
     - missing value, gap
     - значение NaN в ряду
   * - политика обработки пропусков
     - missing-value policy
     - аргумент ``nan_policy``: omit, propagate, raise
   * - вес
     - weight
     - множитель вклада пары в сумму и среднее
   * - свёртка
     - reduction
     - превращение массива значений в одно число или сохранение массива (``reduction``)
   * - группировка
     - grouping
     - раздельный расчёт метрики по группам значений
