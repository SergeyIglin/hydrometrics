.. _pitfalls:

===============================
Типичные ошибки интерпретации
===============================

Перечень ловушек, каждая из которых подтверждена расчётом на страницах метрик или в этом руководстве.

Выравнивание рядов нужно делать явно.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

При ``align="strict"`` сдвинутый индекс pandas или координаты xarray дают ``ValueError``; ``align="inner"`` оставляет общие метки. Без меток (numpy, polars) пары идут по позиции, и сдвиг рядов не обнаруживается (:doc:`input_data`).

Хорошая NSE за год не означает воспроизведённой межени.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

NSE определяется пиками; смотрите :ref:`metric-log_nse` и расчёт по сезонам.

KGE 2009 и 2012 гг. сравнивать между собой нельзя.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Отличаются компоненты (α и γ); см. :ref:`metric-kge_2009` и :ref:`metric-kge_2012`.

У KGE нет нуля, подобного ``NSE = 0``.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

По расчёту Knoben et al. прогноз средним даёт около −0,41 для KGE 2009 г.; сама функция при постоянном ``sim`` возвращает NaN (:ref:`metric-kge_2009`).

Знак PBIAS противоположен определению Moriasi et al.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Здесь положительное значение означает завышение; пороги относятся к модулю (:ref:`metric-pbias`).

``r2`` не равна квадрату корреляции.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Занижение на 40 % оставляет квадрат корреляции равным 1, а ``r2`` заметно ниже (:ref:`metric-r2`).

Высокая accuracy у редких событий ничего не доказывает.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Прогноз «события не будет» уже даёт около 0,9 при частоте события 10 % (:ref:`metric-accuracy`).

CRPSS с опорой «среднее» завышает мастерство.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Для рек с режимом берите климатический гидрограф опорой (:ref:`metric-crpss`).

regNSE не видит ошибку фазы.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Перестановка значений внутри года не меняет результат (:ref:`metric-regNSE`).

Многостворовая оценка скрывает малые реки.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Вес растёт как дисперсия (:ref:`metric-nse_variance_weighted`).

``logNSE`` зависит от ``eps``.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Одни нулевые сутки сильно меняют значение (:ref:`metric-log_nse`).

Пропуски, не случайные по сезонам, смещают оценку.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Смотрите ``nan_info`` и сезон пропусков (:doc:`missing_values`).
