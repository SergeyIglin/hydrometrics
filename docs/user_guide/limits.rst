.. _limits:

=================================
Воспроизводимость и ограничения
=================================

Воспроизводимость
-------------------

Метрики детерминированы: одинаковые входы дают одинаковый результат на любом бэкенде. В примерах документации случайные ряды создаются с фиксированным seed (``numpy.random.default_rng(42)``), а все выводы получены запуском при сборке и проверяются ``sphinx.ext.doctest``. Версии зависимостей для сборки закреплены в ``pyproject.toml`` (набор ``docs``).

Чего библиотека не делает
---------------------------

- Не знает, как сопоставить ряды без меток: numpy и polars идут по позиции, а ``align="inner"`` для них не определён.
- Не принимает ``xarray.Dataset`` и ``polars.LazyFrame``.
- Не вычисляет доверительные интервалы и не проверяет значимость значений метрик.
- Не следит за единицами измерения и не пересчитывает шаг по времени.
- Не реализует индекс мастерства Брайера, разрешающую способность, пороговую CRPS, уточнённый индекс Уилмотта и многомерный NSE на главных компонентах.
- Не разрезает дополнительные массивы (``dates``, ``ref_date``, ``gauge``, веса) при группировке: такие вызовы дают ``NotImplementedError``.

Подробный перечень ограничений и открытых вопросов: :doc:`known_limits`.
