## Этап 3

5. **D3: `bounds=(0, None)` верно и при `fair=True`.** Решение D3 утверждает, что граница верна только
   при `fair=False`. Это неверно: из `|X_j−X_k| ≤ |X_j−o| + |X_k−o|` следует
   `Σ_{j≠k}|X_j−X_k| ≤ 2(m−1)·Σ_j|X_j−o|`, то есть и fair-оценка неотрицательна. Проверено также
   случайным поиском (`tests/test_crps.py`, m от 2 до 20). В докстринге записано истинное
   утверждение; `bounds` не менялись.
6. **D3: `fair` нет у `crpss` и `weighted_crps`.** Оба используют классическую оценку и параметра
   `fair` не получили (правило 7: сигнатуры вне решения не расширялись). Нужно ли добавить `fair`
   в обе функции?
7. **Ансамблевый `crps` на pandas, polars, xarray** раньше возвращал массив по срокам, теперь скаляр
   (согласовано с numpy и с D10). Возврат массива по срокам остался только на numpy при
   `reduction="none"`.

8. **D5: `ssigma_delta`, `forecast_verification`, `forecast_verification_delta` и σ_Δ источника.**
   В лекционном материале по гидрологическим прогнозам (ЗабГУ) допустимая погрешность равна
   меньшему из `0,674σ` и `0,674σ_Δ`, где σ_Δ это стандартное отклонение *изменения* величины за
   заблаговременность прогноза (формула 2.4: разность начального и конечного значений за период
   заблаговременности). В библиотеке: `forecast_verification` использует только σ по всем
   наблюдениям (без `min`), `forecast_verification_delta` использует СКО ошибок прогноза внутри
   группы `ref_date`, `ssigma_delta` использует СКО наблюдений внутри группы `ref_date`. Ни одна из
   трёх не считает σ_Δ источника. Математика и имена по D5 не менялись, в докстринги добавлено
   предупреждение. Нужно решение автора: реализовать критерий источника (с `min`) или переименовать
   функции. **Закрыт (task_5, E3):** оставлено по решению автора, расхождение с σ_Δ источника описано в докстрингах
   и на страницах.
9. **Пункт 25: пределы EDI и SEDI.** Текст Ferro & Stephenson (2011) недоступен (403), определённых
   значений при `H = 1, F = 0` и `H = 1, F > 0` по источнику установить нельзя. Оставлен NaN. При
   `H = 1`, `0 < F < 1` формула EDI даёт 1 (`log H = 0`), и это значение сохранено.
10. **Пункт 21: допуск нулевой дисперсии.** Принят `ZERO_VARIANCE_RTOL = 1e-24` (коэффициент вариации
    ниже 1e-12). Подходит ли такая граница для рядов уровней воды с очень малой изменчивостью?
