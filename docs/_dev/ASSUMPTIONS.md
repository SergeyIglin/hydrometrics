# Допущения и принятые решения

> Примечание (task_5): параметр `sentinel` удалён, метрика `nnse` переименована в `nse_bounded`. Упоминания ниже исторические.

Что принято при написании документации без подтверждения автора. Связанные файлы: `UNVERIFIED_REFS.md`,
`OPEN_QUESTIONS.md`, `BACKLOG.md`, `STYLE.md`.

## Данные и время

- Все примеры работают на синтетическом суточном гидрографе (1096 значений, три года, `default_rng(42)`).
  Реального створа нет, поэтому числа в примерах показывают поведение метрик, а не качество какой-либо
  модели.
- Водный год в примерах начинается 1 октября и назван по году окончания. Это соглашение документации; в
  библиотеке водный год не задан, группировку по нему пользователь строит сам (`df["water_year"]`).
- `regNSE` и функции среднего годового гидрографа считают по календарным годам, поэтому их примеры
  используют ряд с 1 января (`CAL_SETUP`). Остальные примеры берут водные годы.

## Формат и сборка

- Выбран reStructuredText, а не MyST: на нём работают `testcode`, `testoutput`, `footcite`,
  `list-table` без дополнительных расширений.
- Сборка PDF не проверялась.
- Сборка на Read the Docs не запускалась; проверена только локальная сборка.
- Английская версия получается из памяти переводов `tm.json`. Перевод выполнен вместе с русским
  текстом и не проходил проверку носителем языка.

## Источники

- Георгиевский и Шаночкин (2007) оставлены источником для `ssigma`, `ssigma_delta`,
  `forecast_verification`, `forecast_verification_delta`. Текст не читался, градации качества не даны,
  формулы взяты из реализации (подробности в `UNVERIFIED_REFS.md`). Решение автора 8 в
  `OPEN_QUESTIONS.md`: формулы верны, коэффициент 0.674.
- Значения Moriasi et al. (2007), таблица 4, взяты из прочитанного текста PDF. Moriasi et al. (2015)
  читались только по аннотации, поэтому их пороги не приводятся как таблица.
- Формулы Krause et al. (2005), Willmott и Criss и Winston (2008) взяты из реализации. У Krause
  прочитаны определения r², NSE, ln E, d; модифицированные формы E_j в текст не заносились. У
  Criss и Winston формула VE по первоисточнику не проверена.
- Пределы EDI и SEDI при `H = 1`, `F = 0` по Ferro и Stephenson (2011) не проверены; возвращается NaN.
- Ссылки на Seibert (2001) для `log_nse` и Legates и McCabe (1999) для `nnse` сняты.

## Состав документации

- Англоязычные докстринги не переводились: справочник API строится из них через autosummary, так что
  страницы API английские в обоих языках.
- Метрики вне названий в задании найдены инвентаризацией (`INVENTORY.md`) и описаны наравне с остальными.
- Три функции `registry`, `mean_annual_hydrograph`, `mean_annual_hydrograph_duration_curve` описаны на
  `docs/api/helpers.rst` как вспомогательные (решение 1).

## Известные пределы

- `compute_grouped` не разрезает дополнительные массивы (`ref_date`, `gauge`, `dates`) по группе. Для
  `regNSE` и групповых прогнозных критериев срез делается вручную, как в примерах (в `BACKLOG.md`).
- `compute_grouped` работает со скалярными результатами; метрики, возвращающие массив или словарь,
  группируются в цикле.
- `xarray.Dataset` не поддерживается (`NotImplementedError`), в `BACKLOG.md`.
- `polars.LazyFrame` не поддерживается; индексы pandas и координаты xarray не используются, пары
  сопоставляются по позиции.
- `ssigma_delta`, `forecast_verification_delta`, `regNSE`, `nse_variance_weighted` не принимают ось;
  `ssigma`, эти четыре метрики и ряд ранговых не принимают веса (см. `metricpage.py`).
- Многомерный NSE на главных компонентах (PCA) не реализован.
