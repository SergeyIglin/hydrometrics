# Read the Docs: что сделать автору

Порядок действий вместе с GitHub и PyPI: `PUBLISHING.md`.

Сборка на Read the Docs из этой подготовки не запускалась (нет доступа). Конфигурация лежит в `.readthedocs.yaml`
(Ubuntu 24.04, Python 3.13, установка пакета с набором `docs`, `fail_on_warning: true`). Окружение, близкое к RTD,
проверено локально, см. `PACKAGING.md`.

## Действия

1. Войти на readthedocs.org и подключить GitHub-аккаунт, импортировать репозиторий `SergeyIglin/hydrometrics`.
2. Создать основной проект `hydrometrics`. В *Admin → Settings* указать язык **Russian**, ветку по умолчанию `main`.
3. Запустить первую сборку версии `latest`, дождаться зелёного статуса.
4. Создать второй проект из того же репозитория: `hydrometrics-en`, язык **English**, та же ветка.
5. В основном проекте открыть *Admin → Translations* и добавить `hydrometrics-en` как перевод. Проект-перевод должен
   иметь тот же репозиторий и другой язык; адреса станут `/ru/latest/` и `/en/latest/`.
6. В обоих проектах открыть *Admin → Advanced Settings* и проверить, что используется конфигурационный файл репозитория
   (`.readthedocs.yaml`), а не настройки в интерфейсе.
7. Включить сборку по тегам: после создания тега `v0.1.0` (см. `RELEASE_CHECKLIST.md`) открыть *Versions*, активировать
   версию с этим тегом в обоих проектах (в `hydrometrics-en` версии нужно активировать отдельно) и при желании
   назначить её версией по умолчанию (*Admin → Advanced Settings → Default version*).
8. Убедиться, что сборка включает вебхук GitHub (*Admin → Integrations*), чтобы пуши запускали сборки.
9. Заменить заглушку адреса в `README.md` (`hydrometrics.readthedocs.io`) и в `pyproject.toml` (`Documentation`) на
   реальный, если он отличается.

## Проверить глазами после первой сборки

- Сборка `latest` обоих проектов завершилась без предупреждений (при `fail_on_warning: true` предупреждение роняет сборку).
- Переключатель языка в шапке (`docs/_templates/lang-switch.html`) ведёт с русской страницы на ту же английскую и обратно,
  а не на главную. Проверить на странице метрики, например `metrics/nse`.
- Всплывающее меню Read the Docs (flyout) показывает оба языка и версии.
- Формулы отображаются (MathJax), в том числе в таблицах и в блоке «Математическое определение».
- Ссылки на литературу: список «Литература» на страницах метрик, ссылки DOI открываются.
- Блоки кода: кнопка копирования работает, вывод примеров соответствует тексту.
- Сводная таблица `metrics/index` и боковая навигация содержат все семейства; таблицы не выходят за ширину страницы
  на узком экране.
- Тёмная тема читаема (контраст таблиц и кода).
- Страница «Известные ограничения» присутствует в навигации.
- Поиск находит названия метрик на обоих языках.
- Английская версия: в русской сборке докстринги справочника API остаются английскими, в английской сборке весь
  текст английский; нет оставшихся кириллических строк, кроме колонки русских терминов глоссария.
- Размер и время сборки укладываются в лимиты тарифа.
