## Что требует решения автора

См. `docs/_dev/OPEN_QUESTIONS.md` (вопросы 3, 4, 7, 9 без комментария) и `docs/_dev/BACKLOG.md`. Дополнительно:

Решения по замечаниям к первому отчёту приняты в `task_4.txt` и реализованы (проверки `m`, `obs`/`sim`, `n_bins`;
единое правило 366 в 365; веса в `reliability`; EDI и SEDI равны 1 при `H = 1`, `F = 0`). Осталось:

1. Пределы EDI и SEDI при `H = 1`, `0 < F < 1` и прочих вырожденных случаях (EDI даёт 1, SEDI NaN) по
   первоисточнику не проверены.
2. Применение правил `regNSE` к неполным годам (первые ранги кривой режима) оставлено как есть.

## Что не подтверждено

- Георгиевский и Шаночкин (2007): текст не читался, источник сохранён по решению автора для `ssigma`,
  `ssigma_delta`, `forecast_verification`, `forecast_verification_delta`; градации качества не приводятся.
- Формулы `log_nse`, `modified_nse`, `ve`, `edi`, `sedi`, `regNSE` приведены по реализации; тексты Krause (ln E и E_j),
  Criss и Winston, Ferro и Stephenson, Gartsman (2023) для этих формул не сверялись.
- Moriasi et al. (2015): только аннотация. Источник формы `NSE/(2-NSE)` для `nnse` не найден.
- Подробнее: `docs/_dev/UNVERIFIED_REFS.md`.

## Конфликты инструкции с кодом (приоритет у кода)

- В `Task.txt` метрики названы NSE, KGE, RMSE; библиотека содержит 44 публичные метрики, документированы все.
- Модули `hydrometrics.backends.*` не предназначены для прямого вызова, поэтому отдельные страницы бэкендов
  содержат описание без автодокументации.
