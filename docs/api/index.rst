================
Справочник API
================

Справочник построен автоматически из докстрингов. Определения, формулы, интерпретация и примеры находятся на страницах метрик; здесь только сигнатуры и описание параметров, поэтому тексты не дублируются.

Докстринги написаны на английском и не переводятся: русская версия документации показывает их на английском языке.

- Метрики: :doc:`metrics`
- Результаты, группировка, декоратор метрики и реестр: :doc:`core`
- Бэкенды: :doc:`backends`
- Функции режимных кривых и реестр: :doc:`helpers`
