# KGE 2009 (Kling-Gupta Efficiency)

## Название и назначение

**Kling-Gupta Efficiency (KGE) 2009** — декомпозируемая метрика качества гидрологического моделирования, разбивающая ошибку модели на три компоненты: корреляцию, смещение (bias) и вариабельность (alpha). Предложена как альтернатива NSE, которая может быть недостаточно чувствительна к систематическим ошибкам.

Позволяет диагностировать, *какую именно* ошибку совершает модель: плохо воспроизводит динамику (корреляция), систематически завышает/занижает (bias), или неправильно передаёт вариабельность (variability).

## Математическая формула

$$\text{KGE} = 1 - \sqrt{(r - 1)^2 + (\alpha - 1)^2 + (\beta - 1)^2}$$

Где:
- $r = \text{corr}(y, \hat{y})$ — корреляция Пирсона между наблюдениями и моделью
- $\beta = \frac{\bar{\hat{y}}}{\bar{y}}$ — отношение средних (bias ratio)
- $\alpha = \frac{\sigma_{\hat{y}}}{\sigma_y}$ — отношение стандартных отклонений (variability ratio)
- $\bar{y}, \bar{\hat{y}}$ — средние значения
- $\sigma_y, \sigma_{\hat{y}}$ — стандартные отклонения

**Реализация** (`_kge_2009_core`):
- Вычисляет три компонента независимо
- Возвращает KGE и его компоненты в `meta`
- Использует `np.nansum` для обработки NaN
- Поддерживает взвешенное вычисление, `axis`, `reduction`

## Интерпретация

| Значение | Интерпретация |
|----------|---------------|
| **1.0** | Идеальное совпадение (r=1, β=1, α=1) |
| **0.0** | Эквивалентно NSE=0 (по Евклидову расстоянию в пространстве компонент) |
| **< 0.0** | Хуже, чем наивный прогноз |
| **(-∞, 1.0]** | Теоретический диапазон |

**Компоненты (все стремятся к 1.0):**
- **r = 1**: идеальная корреляция (фаза/динамика)
- **β = 1**: нет систематического смещения (bias)
- **α = 1**: правильная вариабельность (амплитуда колебаний)

Направление: **maximize**
Идеальное значение: **1.0**

## Публичный API

```python
from hydrometrics import kge_2009

result = kge_2009(
    obs: array-like,
    sim: array-like,
    *,
    weight: array-like | None = None,
    axis: int | None = None,
    reduction: Literal["mean", "sum", "none"] = "mean",
    nan_policy: Literal["omit", "propagate", "raise"] = "omit",
    sentinel: float | list[float] | None = None,
) -> MetricResult
```

**Импорт**: `from hydrometrics import kge_2009`

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `obs` | array-like | обязательный | Наблюдаемые значения |
| `sim` | array-like | обязательный | Смоделированные значения |
| `weight` | array-like | `None` | Веса выборки |
| `axis` | int | `None` | Ось для вычислений |
| `reduction` | str | `"mean"` | Редукция для массивов |
| `nan_policy` | str | `"omit"` | Политика NaN |
| `sentinel` | float/list | `None` | Значения-пропуски |

**Возвращает**: `MetricResult` с `meta` содержащим `components`: `{"r": float, "beta": float, "alpha": float}`

## Python пример

```python
import numpy as np
from hydrometrics import kge_2009

obs = np.array([10, 12, 15, 14, 13, 11, 9, 8, 7, 9])
sim = np.array([9.5, 11.8, 14.5, 14.2, 13.5, 10.8, 8.8, 7.5, 6.8, 8.5])

result = kge_2009(obs, sim)
print(result)
# Kling-Gupta Efficiency 2009: 0.9401 (direction: maximize, bounds: (-inf, 1.0))

# Доступ к компонентам (если доступны в meta)
print(f"r (correlation): {result.meta.get('components', {}).get('r', 'N/A')}")
print(f"β (bias ratio): {result.meta.get('components', {}).get('beta', 'N/A')}")
print(f"α (variability ratio): {result.meta.get('components', {}).get('alpha', 'N/A')}")
```

**Ожидаемый вывод:**
```
Kling-Gupta Efficiency 2009: 0.9401 (direction: maximize, bounds: (-inf, 1.0))
r (correlation): 0.9940
β (bias ratio): 0.9806
α (variability ratio): 1.0563
```

## Диагностика по компонентам

| Проблема | Компонент | Значение |
|----------|-----------|----------|
| Модель не ловит пики/фазы | `r` | << 1 |
| Систематический пересчёт | `β` | ≠ 1 (β > 1 — завышение) |
| Неверная амплитуда колебаний | `α` | ≠ 1 (α > 1 — переоценка вариабельности) |
