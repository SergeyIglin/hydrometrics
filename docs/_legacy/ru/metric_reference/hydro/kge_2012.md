# KGE 2012 (Kling-Gupta Efficiency)

## Название и назначение

**KGE 2012** — улучшенная версия KGE 2009, добавляющая четвёртую компоненту $\gamma$ (отношение коэффициентов вариации) для лучшего улавливания формы распределения расходов. Компонента вариабельности использует $lpha = rac{\sigma_{\hat{y}}}{\sigma_y}$ (отношение стандартных отклонений) вместо $\gamma$ из KGE 2009.

В настоящее время рекомендуемая версия KGE для гидрологических приложений.

## Математическая формула

$$	ext{KGE}_{2012} = 1 - \sqrt{(r - 1)^2 + (eta - 1)^2 + (lpha - 1)^2 + (\gamma - 1)^2}$$

Где:
- $r = 	ext{corr}(y, \hat{y})$ — корреляция Пирсона
- $eta = rac{ar{\hat{y}}}{ar{y}}$ — отношение средних (bias ratio)
- $lpha = rac{\sigma_{\hat{y}}}{\sigma_y}$ — отношение стандартных отклонений (variability ratio)
- $\gamma = rac{	ext{CV}_{\hat{y}}}{	ext{CV}_y} = rac{\sigma_{\hat{y}} / ar{\hat{y}}}{\sigma_y / ar{y}}$ — отношение коэффициентов вариации

**Реализация** (`_kge_2012_core`):
- Вычисляет все четыре компоненты
- Возвращает только значение KGE
- Компоненты в `meta`: `{"r": float, "beta": float, "alpha": float, "gamma": float}`

## Интерпретация

| Значение | Интерпретация |
|----------|---------------|
| **1.0** | Идеальное совпадение (r=1, β=1, α=1, γ=1) |
| **0.0** | Эквивалентно NSE=0 |
| **< 0.0** | Хуже, чем наивный прогноз |
| **(-∞, 1.0]** | Теоретический диапазон |

**Компоненты (все стремятся к 1.0):**
- **r = 1**: идеальная корреляция
- **β = 1**: нет систематического смещения
- **α = 1**: правильная вариабельность (std модели = std наблюдений)
- **γ = 1**: правильная форма распределения расходов (CV ratio)

Направление: **maximize**
Идеальное значение: **1.0**

## Публичный API

```python
from hydrometrics import kge_2012

result = kge_2012(
    obs: array-like,
    sim: array-like,
    *,
    weight: array-like | None = None,
    axis: int | None = None,
    reduction: Literal["mean", "sum", "none"] = "mean",
    nan_policy: Literal["omit", "propagate", "raise"] = "omit",
    sentinel: float | list[float] | None = None,
) -> MetricResult
```

**Импорт**: `from hydrometrics import kge_2012`

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `obs` | array-like | обязательный | Наблюдаемые значения |
| `sim` | array-like | обязательный | Смоделированные значения |
| `weight` | array-like | `None` | Веса выборки |
| `axis` | int | `None` | Ось для вычислений |
| `reduction` | str | `"mean"` | Редукция для массивов |
| `nan_policy` | str | `"omit"` | Политика NaN |
| `sentinel` | float/list | `None` | Значения-пропуски |

**Возвращает**: `MetricResult` с `meta` содержащим `components`: `{"r": float, "beta": float, "alpha": float, "gamma": float}`

## Python пример

```python
import numpy as np
from hydrometrics import kge_2012

obs = np.array([10, 12, 15, 14, 13, 11, 9, 8, 7, 9])
sim = np.array([9.5, 11.8, 14.5, 14.2, 13.5, 10.8, 8.8, 7.5, 6.8, 8.5])

result = kge_2012(obs, sim)
print(result)
# Kling-Gupta Efficiency 2012: 0.9022 (direction: maximize, bounds: (-inf, 1.0))

print(f"r (correlation): {result.meta['components']['r']:.4f}")
print(f"β (bias ratio): {result.meta['components']['beta']:.4f}")
print(f"α (variability ratio): {result.meta['components']['alpha']:.4f}")
print(f"γ (CV ratio): {result.meta['components']['gamma']:.4f}")
```

**Ожидаемый вывод:**
```
Kling-Gupta Efficiency 2012: 0.9022 (direction: maximize, bounds: (-inf, 1.0))
r (correlation): 0.9940
β (bias ratio): 0.9806
α (variability ratio): 1.0563
γ (CV ratio): 1.0773
```

## Преимущества перед KGE 2009

- $lpha$ более интуитивна, чем $\gamma$ KGE 2009: просто отношение стандартных отклонений
- Не страдает от проблем с малыми средними значениями
- Добавляет компоненту $\gamma$ для явного улавливания формы распределения расходов
- Рекомендуется авторами (Kling et al., 2012) как основная версия
