# Гидрологические метрики

**Полный справочник гидрологических метрик в HydroMetrics**

Этот раздел содержит все гидрологические метрики, реализованные в библиотеке. Каждая метрика имеет свою отдельную страницу с проверенной математической формулой, объяснением и рабочим примером на Python.

## Категории гидрологических метрик

### Семейство NSE (Наш-Сатклифф)
Метрики эффективности моделирования на основе соотношения суммы квадратов ошибок к дисперсии наблюдений.

| Метрика | Функция | Направление | Границы | Описание |
|---------|---------|-------------|---------|----------|
| **Коэффициент Наша-Сатклиффа** | `nse` | maximize | (-∞, 1.0] | Классическая метрика качества моделирования |
| **Логарифмический NSE** | `log_nse` | maximize | (-∞, 1.0] | Акцент на малые расходы через лог-трансформацию |
| **Модифицированный NSE** | `modified_nse` | maximize | (-∞, 1.0] | Использует абсолютные ошибки (j=1) или квадратичные (j=2) |
| **Нормализованный NSE** | `nnse` | maximize | [0, 1] | Ограниченный вариант NSE в диапазоне [0, 1] |
| **Вариационно-взвешенный NSE** | `nse_variance_weighted` | maximize | (-∞, 1.0] | Мульти-стационарный NSE с весами по дисперсии |

### Семейство KGE (Клинг-Гупта)
Декомпозируемые метрики эффективности, разделяющие корреляцию, вариабельность и смещение.

| Метрика | Функция | Направление | Границы | Описание |
|---------|---------|-------------|---------|----------|
| **KGE 2009 (оригинал)** | `kge_2009` | maximize | (-∞, 1.0] | Три компоненты: r, α, β |
| **KGE 2012 (модифицированная)** | `kge_2012` | maximize | (-∞, 1.0] | Четыре компоненты: r, α, β, γ (рекомендуется) |
| **Компоненты KGE** | `kge_components` | — | — | Возвращает словарь со всеми компонентами |

#### Отдельные компоненты KGE
| Компонента | Функция | Символ | Идеальное значение | Интерпретация |
|------------|---------|--------|-------------------|---------------|
| **Корреляция** | `r_component` | r | 1.0 | Линейная связь между obs и sim |
| **Отношение вариабельности** | `alpha_component` | α | 1.0 | Соответствие разброса симуляции наблюдениям |
| **Отношение смещения** | `beta_component` | β | 1.0 | Отсутствие систематического смещения |
| **Отношение коэф. вариации** | `gamma_component` | γ | 1.0 | Соответствие формы распределения расходов (только KGE 2012) |

### Другие гидрологические метрики

| Метрика | Функция | Направление | Границы | Описание |
|---------|---------|-------------|---------|----------|
| **Отношение RMSE к Std Dev** | `rsr` | minimize | [0, ∞) | RSR = RMSE / σ(obs), связан с NSE: NSE = 1 - RSR² |
| **Объёмная эффективность** | `ve` | maximize | (-∞, 1.0] | Соответствие объёмов, нечувствительна к таймингу |
| **Режимный NSE** | `regNSE` | maximize | (-∞, 1.0] | NSE на ранжированных кривых длительности (режиме) |
| **Верификация прогноза** | `forecast_verification` | maximize | (-∞, 1.0] | Умение относительно климатологии |
| **Верификация дельт** | `forecast_verification_delta` | maximize | (-∞, 1.0] | Умение на приращениях расхода |
| **Сигма-скилл** | `ssigma` | maximize | (-∞, 1.0] | Комбинация RMSE и штрафа за смещение |
| **Сигма-скилл дельт** | `ssigma_delta` | maximize | (-∞, 1.0] | Сигма-скилл на приращениях |

## Общие параметры

Все гидрологические метрики поддерживают общие параметры:

```python
def metric(
    obs: array-like,
    sim: array-like,
    *,
    weight: array-like | None = None,
    axis: int | None = None,
    reduction: Literal["mean", "sum", "none"] = "mean",
    **kwargs
) -> MetricResult:
```

| Параметр | Описание |
|----------|----------|
| `obs` | Наблюдаемые значения |
| `sim` | Смоделированные/прогнозируемые значения |
| `weight` | Веса выборки (broadcastable к obs/sim) |
| `axis` | Ось для вычислений (None = сплющить) |
| `reduction` | "mean", "sum" или "none" для массивов |

## Особенности реализации

- **Автоматический диспатчинг**: Работает с NumPy, pandas, xarray, polars
- **Обработка NaN**: Три политики (`omit`, `propagate`, `raise`) через `nan_policy`
- **Sentinel values**: Поддержка кодов пропусков (например, -999) через параметр `sentinel`
- **Возврат MetricResult**: Богатый объект с метаданными, формулой, ссылками
