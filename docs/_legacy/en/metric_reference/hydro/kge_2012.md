# KGE 2012 (Kling-Gupta Efficiency)

## Name and Purpose

**KGE 2012** — improved version of KGE 2009 that adds a fourth component $\gamma$ (coefficient of variation ratio) to better capture flow distribution shape. The variability component uses $\alpha = \frac{\sigma_{\hat{y}}}{\sigma_y}$ (ratio of standard deviations) instead of $\gamma$ from KGE 2009.

Currently the recommended KGE version for hydrological applications.

## Mathematical Formula

$$\text{KGE}_{2012} = 1 - \sqrt{(r - 1)^2 + (\beta - 1)^2 + (\alpha - 1)^2 + (\gamma - 1)^2}$$

Where:
- $r = \text{corr}(y, \hat{y})$ — Pearson correlation
- $\beta = \frac{\bar{\hat{y}}}{\bar{y}}$ — ratio of means (bias ratio)
- $\alpha = \frac{\sigma_{\hat{y}}}{\sigma_y}$ — ratio of standard deviations (variability ratio)
- $\gamma = \frac{\text{CV}_{\hat{y}}}{\text{CV}_y} = \frac{\sigma_{\hat{y}} / \bar{\hat{y}}}{\sigma_y / \bar{y}}$ — ratio of coefficients of variation

**Implementation** (`_kge_2012_core`):
- Computes all four components
- Returns KGE value only
- Components in `meta`: `{"r": float, "beta": float, "alpha": float, "gamma": float}`

## Interpretation

| Value | Interpretation |
|-------|----------------|
| **1.0** | Perfect match (r=1, β=1, α=1) |
| **0.0** | Equivalent to NSE=0 |
| **< 0.0** | Worse than naive forecast |
| **(-∞, 1.0]** | Theoretical range |

**Components (all target 1.0):**
- **r = 1**: perfect correlation
- **β = 1**: no systematic bias
- **α = 1**: correct variability (model std = obs std)
- **γ = 1**: correct flow distribution shape (CV ratio)

Direction: **maximize**
Ideal value: **1.0**

## Public API

```python
from hydrometrics import kge_2012

result = kge_2012(
    obs: array-like,
    sim: array-like,
    *,
    weight: array-like | None = None,
    axis: int | None = None,
    reduction: Literal["mean", "sum", "none"] = "mean",
    nan_policy: Literal["omit", "propagate", "raise"] = "omit",
    sentinel: float | list[float] | None = None,
) -> MetricResult
```

**Import**: `from hydrometrics import kge_2012`

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `obs` | array-like | required | Observed values |
| `sim` | array-like | required | Simulated values |
| `weight` | array-like | `None` | Sample weights |
| `axis` | int | `None` | Axis for computation |
| `reduction` | str | `"mean"` | Reduction for arrays |
| `nan_policy` | str | `"omit"` | NaN policy |
| `sentinel` | float/list | `None` | Missing value codes |

**Returns**: `MetricResult` with `meta` containing `components`: `{"r": float, "beta": float, "alpha": float, "gamma": float}`

## Python Example

```python
import numpy as np
from hydrometrics import kge_2012

obs = np.array([10, 12, 15, 14, 13, 11, 9, 8, 7, 9])
sim = np.array([9.5, 11.8, 14.5, 14.2, 13.5, 10.8, 8.8, 7.5, 6.8, 8.5])

result = kge_2012(obs, sim)
print(result)
# Kling-Gupta Efficiency 2012: 0.9022 (direction: maximize, bounds: (-inf, 1.0))

print(f"r (correlation): {result.meta['components']['r']:.4f}")
print(f"β (bias ratio): {result.meta['components']['beta']:.4f}")
print(f"α (variability ratio): {result.meta['components']['alpha']:.4f}")
print(f"γ (CV ratio): {result.meta['components']['gamma']:.4f}")
```

**Expected Output:**
```
Kling-Gupta Efficiency 2012: 0.9022 (direction: maximize, bounds: (-inf, 1.0))
r (correlation): 0.9940
β (bias ratio): 0.9806
α (variability ratio): 1.0563
γ (CV ratio): 1.0773
```

## Advantages over KGE 2009

- $\alpha$ is more intuitive than KGE 2009's $\gamma$: simply ratio of standard deviations
- Does not suffer from issues with small mean values
- Adds $\gamma$ component to explicitly capture flow distribution shape
- Recommended by authors (Kling et al., 2012) as primary version
