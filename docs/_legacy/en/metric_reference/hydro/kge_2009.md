# KGE 2009 (Kling-Gupta Efficiency)

## Name and Purpose

**Kling-Gupta Efficiency (KGE) 2009** is a decomposable hydrological model evaluation metric that breaks down model error into three components: correlation, bias, and variability. Proposed as an alternative to NSE, which can be insufficiently sensitive to systematic errors.

Allows diagnosing *which* error the model makes: poor dynamics reproduction (correlation), systematic over/underestimation (bias), or incorrect variability representation (variability).

## Mathematical Formula

$$\text{KGE} = 1 - \sqrt{(r - 1)^2 + (\alpha - 1)^2 + (\beta - 1)^2}$$

Where:
- $r = \text{corr}(y, \hat{y})$ — Pearson correlation between observations and model
- $\beta = \frac{\bar{\hat{y}}}{\bar{y}}$ — ratio of means (bias ratio)
- $\alpha = \frac{\sigma_{\hat{y}}}{\sigma_y}$ — ratio of standard deviations (variability ratio)
- $\bar{y}, \bar{\hat{y}}$ — mean values
- $\sigma_y, \sigma_{\hat{y}}$ — standard deviations

**Implementation** (`_kge_2009_core`):
- Computes three components independently
- Returns KGE and its components in `meta`
- Uses `np.nansum` for NaN handling
- Supports weighted computation, `axis`, `reduction`

## Interpretation

| Value | Interpretation |
|-------|----------------|
| **1.0** | Perfect match (r=1, β=1, γ=1) |
| **0.0** | Equivalent to NSE=0 (by Euclidean distance in component space) |
| **< 0.0** | Worse than naive forecast |
| **(-∞, 1.0]** | Theoretical range |

**Components (all target 1.0):**
- **r = 1**: perfect correlation (phase/dynamics)
- **β = 1**: no systematic bias
- **α = 1**: correct variability (amplitude of fluctuations)

Direction: **maximize**
Ideal value: **1.0**

## Public API

```python
from hydrometrics import kge_2009

result = kge_2009(
    obs: array-like,
    sim: array-like,
    *,
    weight: array-like | None = None,
    axis: int | None = None,
    reduction: Literal["mean", "sum", "none"] = "mean",
    nan_policy: Literal["omit", "propagate", "raise"] = "omit",
    sentinel: float | list[float] | None = None,
) -> MetricResult
```

**Import**: `from hydrometrics import kge_2009`

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `obs` | array-like | required | Observed values |
| `sim` | array-like | required | Simulated values |
| `weight` | array-like | `None` | Sample weights |
| `axis` | int | `None` | Axis for computation |
| `reduction` | str | `"mean"` | Reduction for arrays |
| `nan_policy` | str | `"omit"` | NaN policy |
| `sentinel` | float/list | `None` | Missing value codes |

**Returns**: `MetricResult` with `meta` containing `components`: `{"r": float, "beta": float, "gamma": float}`

## Python Example

```python
import numpy as np
from hydrometrics import kge_2009

obs = np.array([10, 12, 15, 14, 13, 11, 9, 8, 7, 9])
sim = np.array([9.5, 11.8, 14.5, 14.2, 13.5, 10.8, 8.8, 7.5, 6.8, 8.5])

result = kge_2009(obs, sim)
print(result)
# KGE 2009: 0.9456 (direction: maximize, bounds: (-inf, 1.0))

# Access components
print(f"r (correlation): {result.meta['components']['r']:.4f}")
print(f"β (bias ratio): {result.meta['components']['beta']:.4f}")
print(f"γ (variability ratio): {result.meta['components']['gamma']:.4f}")
```

**Expected Output:**
```
KGE 2009: 0.9456 (direction: maximize, bounds: (-inf, 1.0))
r (correlation): 0.9876
β (bias ratio): 0.9923
γ (variability ratio): 0.9654
```

## Component Diagnostics

| Issue | Component | Value |
|-------|-----------|-------|
| Model misses peaks/phases | `r` | << 1 |
| Systematic over/underestimation | `β` | ≠ 1 (β > 1 = overestimation) |
| Wrong fluctuation amplitude | `α` | ≠ 1 (α > 1 = overestimated variability) |
