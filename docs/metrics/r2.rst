.. _metric-r2:

===============================
Коэффициент детерминации (R²)
===============================

``r2`` это доля дисперсии наблюдений, объяснённая моделью, в определении «1 минус отношение суммы квадратов остатков к полной сумме квадратов». Это не квадрат коэффициента корреляции.

Сигнатура
-----------

.. code-block:: python

   hydrometrics.r2(obs, sim, *, axis=None, nan_policy="omit",
       sample_weight=None, weight=None, reduction=None, align="strict")

Запись в справочнике API: :func:`hydrometrics.r2`. На xarray вместо ``axis`` используется ``dim``; остальные параметры одинаковы на всех бэкендах.

Математическое определение
----------------------------

.. math::

   R^2 = 1 - \frac{\sum_{i=1}^{n} w_i\,\left(O_i - S_i\right)^2}{\sum_{i=1}^{n} w_i\,\left(O_i - \bar{O}\right)^2}

:math:`O_i` наблюдённое, :math:`S_i` модельное значение, :math:`\bar{O}` среднее наблюдений (взвешенное при заданных весах), :math:`w_i` вес, :math:`n` число действительных пар.

Отличия от классического определения
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В литературе по гидрологическим моделям :math:`r^2` чаще означает квадрат коэффициента корреляции, и он, в отличие от этой метрики, не чувствителен к смещению и масштабу :footcite:p:`krause2005`. Здесь используется определение из регрессионного анализа. Формула совпадает с :ref:`metric-nse` без ``norm``; различаются только вырожденные случаи: при постоянном ``obs`` ``r2`` равна 1 для точного совпадения и NaN иначе, а при отсутствии действительных пар NaN; при всех нулевых весах результат 1.

Диапазон значений и оптимум
-----------------------------

.. list-table::
   :header-rows: 1
   :class: hm-table

   * - Диапазон
     - Оптимум
     - Направление
   * - (-∞, 1]
     - 1
     - больше лучше

Верхняя граница достигается при совпадении рядов. Значение 0 означает, что модель не лучше постоянного прогноза средним наблюдений, отрицательное значение что хуже. Нижней границы нет.

Интерпретация и критерии оценки
---------------------------------

Градаций именно для этой формы нет; поскольку формула совпадает с NSE, на неё распространяются те же ориентиры, что приведены на странице :ref:`metric-nse` (в том числе оговорки об их происхождении).

Параметры
-----------

.. list-table::
   :header-rows: 1
   :class: hm-table
   :widths: 18 16 14 52

   * - Имя
     - Тип
     - По умолчанию
     - Описание
   * - ``obs``
     - массив
     - обязателен
     - Наблюдённые значения.
   * - ``sim``
     - массив
     - обязателен
     - Модельные или прогнозные значения той же формы.
   * - ``axis``
     - int | None
     - ``None``
     - Ось суммирования; ``None`` объединяет все значения. На xarray вместо неё используется ``dim`` (или ``axis``, он переводится в имя измерения).
   * - ``nan_policy``
     - str
     - ``"omit"``
     - ``"omit"`` удаляет пары с пропуском, ``"propagate"`` даёт NaN, ``"raise"`` вызывает ``ValueError``; см. раздел о пропусках ниже и :doc:`/user_guide/missing_values`.
   * - ``sample_weight``
     - массив | None
     - ``None``
     - Веса той же формы, что ``obs``, неотрицательные; NaN делает пару недействительной. ``weight`` принимается как алиас, обе формы сразу вызывают ``TypeError``.
   * - ``reduction``
     - str | None
     - ``None``
     - Свёртка результата с ``ndim > 0``: ``"mean"``, ``"sum"`` или ``"none"``. По умолчанию при заданной оси возвращается массив по оставшимся измерениям, без оси среднее.
   * - ``align``
     - str
     - ``"strict"``
     - ``"strict"`` требует равных индексов pandas и координат xarray, ``"inner"`` оставляет общие метки в порядке ``obs``. Без меток ``"inner"`` вызывает ``ValueError``.

Пропуски и особые случаи
--------------------------

Результаты получены запуском на numpy при сборке этой страницы. Ряд содержит 1096 суточных значений. Пометка ``RuntimeWarning`` означает, что предупреждение numpy выходит наружу.

.. list-table::
   :header-rows: 1
   :class: hm-table
   :widths: 60 40

   * - Случай
     - Результат
   * - NaN в одной паре, ``nan_policy="omit"`` (умолчание)
     - 0.9529
   * - NaN в одной паре, ``nan_policy="propagate"``
     - NaN
   * - NaN в одной паре, ``nan_policy="raise"``
     - ValueError
   * - все ``obs`` равны NaN
     - NaN (RuntimeWarning)
   * - ``inf`` в ``obs``
     - NaN (RuntimeWarning)
   * - постоянный ``obs`` (нулевая дисперсия)
     - NaN
   * - ``obs`` и ``sim`` из одних нулей
     - 1
   * - отрицательные значения (ряд минус его среднее)
     - 0.9529
   * - пустой ввод
     - NaN (RuntimeWarning)
   * - разная длина ``obs`` и ``sim``
     - ValueError

При умолчании ``nan_policy="omit"`` пары с пропуском в ``obs`` или ``sim`` удаляются целиком, в том числе при заданной оси. ``"propagate"`` возвращает NaN, если в ряду (или в срезе вдоль оси) есть пропуск, ``"raise"`` вызывает ``ValueError``. Значение ``inf`` пропуском не считается; результат для него показан в таблице.

Постоянный ``obs`` даёт NaN, если ряды не совпадают, и 1, если совпадают. Один элемент даёт NaN.

Примеры
---------

Суточный гидрограф за три водных года с половодьем и меженью, расходы в м³/с.

.. testcode::

   import numpy as np
   import hydrometrics as hm

   rng = np.random.default_rng(42)
   dates = np.arange("2010-10-01", "2013-10-01", dtype="datetime64[D]")
   doy = (dates - dates.astype("datetime64[Y]")).astype(int)
   # Половодье в конце апреля поверх зимней и летней межени, м³/с
   q_obs = 12 + 240 * np.exp(-(((doy - 118) / 16.0) ** 2)) + rng.gamma(2.0, 2.5, doy.size)
   # Модель запаздывает на двое суток и срезает пик
   q_sim = np.clip(0.88 * np.roll(q_obs, 2) + 3 + rng.normal(0, 5, doy.size), 0.1, None)

.. testcode::

   result = hm.r2(q_obs, q_sim)
   print(f"r2 = {float(result):.3f}")

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   r2 = 0.954

Функция ``r2`` не равна квадрату коэффициента корреляции. Для модели с систематическим занижением квадрат корреляции остаётся высоким, а ``r2`` падает:

.. testcode::

   q_low = 0.6 * q_obs  # занижение всех расходов на 40 %
   print(round(float(hm.r2(q_obs, q_low)), 3), round(float(hm.pearson_r(q_obs, q_low)) ** 2, 3))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   0.768 1.0

На тех же данных ``r2`` и :func:`~hydrometrics.nse` совпадают:

.. testcode::

   print(round(float(hm.r2(q_obs, q_sim)), 6), round(float(hm.nse(q_obs, q_sim)), 6))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   0.95375 0.95375

По створам:

.. testcode::

   # Три створа: столбцы массива (время, створ)
   q_obs_st = np.column_stack([q_obs, 0.4 * q_obs + 2, 1.7 * q_obs + 5])
   q_sim_st = np.column_stack([q_sim, 0.35 * q_sim + 4, 1.9 * q_sim])

.. testcode::

   per_station = hm.r2(q_obs_st, q_sim_st, axis=0, reduction="none")
   print(np.round(per_station.value, 3))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   [0.954 0.921 0.963]

По водным годам:

.. testcode::

   import pandas as pd

   df = pd.DataFrame({"q_obs": q_obs, "q_sim": q_sim}, index=pd.to_datetime(dates))
   # Водный год начинается 1 октября и назван по году окончания
   df["water_year"] = df.index.year + (df.index.month >= 10)

.. testcode::

   by_year = hm.compute_grouped(hm.r2, df, "q_obs", "q_sim", group_by="water_year")
   for (water_year,), value in by_year:
       print(int(water_year), round(float(value), 3))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   2011 0.95
   2012 0.957
   2013 0.955

На xarray ось задаётся именем измерения, а координаты створов сохраняются в результате:

.. testcode::

   import xarray as xr

   coords = {"time": dates, "station": ["upper", "middle", "lower"]}
   obs_da = xr.DataArray(q_obs_st, dims=["time", "station"], coords=coords)
   sim_da = xr.DataArray(q_sim_st, dims=["time", "station"], coords=coords)
   by_station = hm.r2(obs_da, sim_da, dim="time").value
   print(by_station.round(3).to_series().to_dict())

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   {'upper': 0.954, 'middle': 0.921, 'lower': 0.963}

Особенности применения в гидрологии
-------------------------------------

Те же свойства, что у :ref:`metric-nse`: значение определяется крупными расходами, межень почти не влияет. Не путайте ``r2`` с квадратом корреляции: в литературе и в других пакетах под :math:`R^2` нередко понимают его.
