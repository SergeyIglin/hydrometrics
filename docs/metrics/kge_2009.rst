.. _metric-kge_2009:

===============================================
Критерий Клинга–Гупты, версия 2009 (KGE 2009)
===============================================

KGE 2009 г. измеряет евклидово расстояние от идеальной точки в пространстве корреляции :math:`r`, отношения стандартных отклонений :math:`\alpha` и отношения средних :math:`\beta` :footcite:p:`gupta2009`. Метрика получена разложением NSE на эти три компоненты.

Сигнатура
-----------

.. code-block:: python

   hydrometrics.kge_2009(obs, sim, *, axis=None, nan_policy="omit",
       sample_weight=None, weight=None, reduction=None, align="strict")

Запись в справочнике API: :func:`hydrometrics.kge_2009`. На xarray вместо ``axis`` используется ``dim``; остальные параметры одинаковы на всех бэкендах.

Математическое определение
----------------------------

.. math::

   \mathrm{KGE}_{2009} = 1 - \sqrt{(r-1)^2 + (\alpha-1)^2 + (\beta-1)^2}

.. math::

   \alpha = \frac{\sigma_S}{\sigma_O}, \qquad \beta = \frac{\mu_S}{\mu_O}

:math:`r` коэффициент корреляции Пирсона, :math:`\sigma` стандартное отклонение с ``ddof=1``, :math:`\mu` среднее, индексы :math:`O` и :math:`S` обозначают наблюдения и модель.

Отличия от классического определения
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Совпадает с определением Gupta et al. :footcite:p:`gupta2009`. Версия 2012 г. :ref:`metric-kge_2012` заменяет :math:`\alpha` отношением коэффициентов вариации :math:`\gamma`; значения двух версий нельзя сравнивать между собой.

Диапазон значений и оптимум
-----------------------------

.. list-table::
   :header-rows: 1
   :class: hm-table

   * - Диапазон
     - Оптимум
     - Направление
   * - (-∞, 1]
     - 1
     - больше лучше

Значение 1 достигается при :math:`r=\alpha=\beta=1`. Снизу значение не ограничено. При среднем наблюдений, близком к нулю, :math:`\beta` не определена или очень велика. Если ряд постоянен, корреляция не определена и результат NaN.

Интерпретация и критерии оценки
---------------------------------

Общепринятых порогов качества для KGE нет. Значение не имеет встроенного ориентира, подобного ``NSE = 0``: Knoben et al. :footcite:p:`knoben2019` показывают, что прогноз средним расходом даёт :math:`1-\sqrt{2}\approx-0.41`, а не 0, и требуют явно указывать опорную модель.

Параметры
-----------

.. list-table::
   :header-rows: 1
   :class: hm-table
   :widths: 18 16 14 52

   * - Имя
     - Тип
     - По умолчанию
     - Описание
   * - ``obs``
     - массив
     - обязателен
     - Наблюдённые значения.
   * - ``sim``
     - массив
     - обязателен
     - Модельные или прогнозные значения той же формы.
   * - ``axis``
     - int | None
     - ``None``
     - Ось суммирования; ``None`` объединяет все значения. На xarray вместо неё используется ``dim`` (или ``axis``, он переводится в имя измерения).
   * - ``nan_policy``
     - str
     - ``"omit"``
     - ``"omit"`` удаляет пары с пропуском, ``"propagate"`` даёт NaN, ``"raise"`` вызывает ``ValueError``; см. раздел о пропусках ниже и :doc:`/user_guide/missing_values`.
   * - ``sample_weight``
     - массив | None
     - ``None``
     - Веса той же формы, что ``obs``, неотрицательные; NaN делает пару недействительной. ``weight`` принимается как алиас, обе формы сразу вызывают ``TypeError``.
   * - ``reduction``
     - str | None
     - ``None``
     - Свёртка результата с ``ndim > 0``: ``"mean"``, ``"sum"`` или ``"none"``. По умолчанию при заданной оси возвращается массив по оставшимся измерениям, без оси среднее.
   * - ``align``
     - str
     - ``"strict"``
     - ``"strict"`` требует равных индексов pandas и координат xarray, ``"inner"`` оставляет общие метки в порядке ``obs``. Без меток ``"inner"`` вызывает ``ValueError``.

Пропуски и особые случаи
--------------------------

Результаты получены запуском на numpy при сборке этой страницы. Ряд содержит 1096 суточных значений. Пометка ``RuntimeWarning`` означает, что предупреждение numpy выходит наружу.

.. list-table::
   :header-rows: 1
   :class: hm-table
   :widths: 60 40

   * - Случай
     - Результат
   * - NaN в одной паре, ``nan_policy="omit"`` (умолчание)
     - 0.914
   * - NaN в одной паре, ``nan_policy="propagate"``
     - NaN
   * - NaN в одной паре, ``nan_policy="raise"``
     - ValueError
   * - все ``obs`` равны NaN
     - NaN (RuntimeWarning)
   * - ``inf`` в ``obs``
     - NaN (RuntimeWarning)
   * - постоянный ``obs`` (нулевая дисперсия)
     - NaN
   * - ``obs`` и ``sim`` из одних нулей
     - NaN
   * - отрицательные значения (ряд минус его среднее)
     - -1.342e+14
   * - пустой ввод
     - NaN (RuntimeWarning)
   * - разная длина ``obs`` и ``sim``
     - ValueError

При умолчании ``nan_policy="omit"`` пары с пропуском в ``obs`` или ``sim`` удаляются целиком, в том числе при заданной оси. ``"propagate"`` возвращает NaN, если в ряду (или в срезе вдоль оси) есть пропуск, ``"raise"`` вызывает ``ValueError``. Значение ``inf`` пропуском не считается; результат для него показан в таблице.

Постоянный ряд даёт NaN из-за корреляции. Один элемент даёт NaN.

Примеры
---------

Суточный гидрограф за три водных года с половодьем и меженью, расходы в м³/с.

.. testcode::

   import numpy as np
   import hydrometrics as hm

   rng = np.random.default_rng(42)
   dates = np.arange("2010-10-01", "2013-10-01", dtype="datetime64[D]")
   doy = (dates - dates.astype("datetime64[Y]")).astype(int)
   # Половодье в конце апреля поверх зимней и летней межени, м³/с
   q_obs = 12 + 240 * np.exp(-(((doy - 118) / 16.0) ** 2)) + rng.gamma(2.0, 2.5, doy.size)
   # Модель запаздывает на двое суток и срезает пик
   q_sim = np.clip(0.88 * np.roll(q_obs, 2) + 3 + rng.normal(0, 5, doy.size), 0.1, None)

.. testcode::

   result = hm.kge_2009(q_obs, q_sim)
   print(f"kge_2009 = {float(result):.4f}")

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   kge_2009 = 0.8804

Независимый пересчёт по трём компонентам:

.. testcode::

   r = np.corrcoef(q_obs, q_sim)[0, 1]
   alpha = q_sim.std(ddof=1) / q_obs.std(ddof=1)
   beta = q_sim.mean() / q_obs.mean()
   by_hand = 1 - np.sqrt((r - 1)**2 + (alpha - 1)**2 + (beta - 1)**2)
   print(f"{by_hand:.4f}")

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   0.8804

От :ref:`metric-kge_2012` версия 2009 г. отличается заменой :math:`\gamma` на :math:`\alpha`; на тех же данных:

.. testcode::

   print(round(float(hm.kge_2009(q_obs, q_sim)), 4), round(float(hm.kge_2012(q_obs, q_sim)), 4))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   0.8804 0.9063

По створам:

.. testcode::

   # Три створа: столбцы массива (время, створ)
   q_obs_st = np.column_stack([q_obs, 0.4 * q_obs + 2, 1.7 * q_obs + 5])
   q_sim_st = np.column_stack([q_sim, 0.35 * q_sim + 4, 1.9 * q_sim])

.. testcode::

   per_station = hm.kge_2009(q_obs_st, q_sim_st, axis=0, reduction="none")
   print(np.round(per_station.value, 3))

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   [0.88  0.774 0.979]

По водным годам:

.. testcode::

   import pandas as pd

   df = pd.DataFrame({"q_obs": q_obs, "q_sim": q_sim}, index=pd.to_datetime(dates))
   # Водный год начинается 1 октября и назван по году окончания

Особенности применения в гидрологии
-------------------------------------

Gupta et al. :footcite:p:`gupta2009` показывают, что NSE складывается из тех же трёх компонент, и что при данной корреляции NSE достигает максимума при :math:`\alpha = r`, то есть оптимальная по NSE модель занижает изменчивость стока. KGE штрафует отклонение :math:`\alpha` от 1 прямо.

Mizukami et al. :footcite:p:`mizukami2019` сообщают, что калибровка по KGE (форма 2009 г.) воспроизводит годовые максимумы стока лучше, чем калибровка по NSE.
