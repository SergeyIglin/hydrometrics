.. _metric-kge_2012:

===========================================
Критерий Клинга–Гупты, версия 2012 (KGE′)
===========================================

Метрика измеряет евклидово расстояние от идеальной точки в пространстве компонент: корреляции :math:`r`, отношения средних :math:`\beta` и отношения коэффициентов вариации :math:`\gamma` :footcite:p:`kling2012`.

Сигнатура
-----------

.. code-block:: python

   hydrometrics.kge_2012(obs, sim, *, axis=None, nan_policy="omit",
       sample_weight=None, weight=None, reduction=None, align="strict")

Запись в справочнике API: :func:`hydrometrics.kge_2012`. На xarray вместо ``axis`` используется ``dim``; остальные параметры одинаковы на всех бэкендах.

Математическое определение
----------------------------

.. math::

   \mathrm{KGE}' = 1 - \sqrt{(r-1)^2 + (\beta-1)^2 + (\gamma-1)^2}

.. math::

   \beta = \frac{\mu_S}{\mu_O}, \quad \gamma = \frac{\sigma_S/\mu_S}{\sigma_O/\mu_O}

:math:`r` коэффициент корреляции Пирсона, :math:`\sigma` стандартное отклонение с ``ddof=1``, :math:`\mu` среднее, индексы :math:`O` и :math:`S` обозначают наблюдения и модель. Без весов суммирование идёт по ``axis``.

Отличия от классического определения
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Реализация совпадает с формой KGE′, приведённой у Santos et al. :footcite:p:`santos2018`: три слагаемых, отношение коэффициентов вариации :math:`\gamma` заменяет отношение стандартных отклонений :math:`\alpha`. Отличий от определения нет.

Версии библиотеки до исправления добавляли четвёртое слагаемое :math:`\alpha`; значения ``kge_2012``, полученные ими, с нынешними несопоставимы (см. ``CHANGELOG.md``). Компонента :math:`\alpha` по-прежнему доступна как :func:`~hydrometrics.alpha_component` и входит в :ref:`metric-kge_2009`.

Диапазон значений и оптимум
-----------------------------

   * - Диапазон
     - Оптимум
     - Направление
   * - (-∞, 1]
     - 1

Значение 1 достигается при :math:`r=\beta=\gamma=1`. При среднем наблюдений, близком к нулю, :math:`\beta` и :math:`\gamma` становятся очень большими, и метрика теряет смысл: на ряде с вычтенным средним она даёт порядка :math:`-10^{14}`. Метрика рассчитана на положительные величины вроде расхода воды.

Интерпретация и критерии оценки
---------------------------------

Общепринятых порогов качества для KGE′ нет. Значение не имеет встроенного ориентира, подобного ``NSE = 0``: Knoben et al. :footcite:p:`knoben2019` показывают для KGE 2009 г., что прогноз средним расходом даёт :math:`1-\sqrt{2}\approx-0.41`, а не 0, и требуют явно указывать опорную модель.

Для трёхчленной формы KGE′ тот же результат получается из формулы: у постоянного прогноза средним :math:`r=0`, :math:`\beta=1`, :math:`\gamma=0`, поэтому :math:`1-\sqrt{1+0+1}`. Это расчёт по формулам; сама функция для постоянного ряда возвращает NaN, потому что корреляция не определена.

Параметры
-----------

   * - ``sim``
     - массив
     - обязателен
     - Модельные или прогнозные значения той же формы.
   * - ``axis``
     - int | None
     - ``None``
     - Ось суммирования; ``None`` объединяет все значения. На xarray вместо неё используется ``dim`` (или ``axis``, он переводится в имя измерения).
   * - ``nan_policy``
     - str
     - ``"omit"``
     - ``"omit"`` удаляет пары с пропуском, ``"propagate"`` даёт NaN, ``"raise"`` вызывает ``ValueError``; см. раздел о пропусках ниже и :doc:`/user_guide/missing_values`.
   * - ``sample_weight``
     - массив | None
     - ``None``
     - Веса той же формы, что ``obs``, неотрицательные; NaN делает пару недействительной. ``weight`` принимается как алиас, обе формы сразу вызывают ``TypeError``.
   * - ``reduction``
     - str | None
     - ``None``
     - Свёртка результата с ``ndim > 0``: ``"mean"``, ``"sum"`` или ``"none"``. По умолчанию при заданной оси возвращается массив по оставшимся измерениям, без оси среднее.
   * - ``align``
     - str
     - ``"strict"``
     - ``"strict"`` требует равных индексов pandas и координат xarray, ``"inner"`` оставляет общие метки в порядке ``obs``. Без меток ``"inner"`` вызывает ``ValueError``.

Примеры
---------

.. testcode::

   import numpy as np
   import hydrometrics as hm

   rng = np.random.default_rng(42)
   dates = np.arange("2010-10-01", "2013-10-01", dtype="datetime64[D]")
   doy = (dates - dates.astype("datetime64[Y]")).astype(int)
   # Половодье в конце апреля поверх зимней и летней межени, м³/с
   q_obs = 12 + 240 * np.exp(-(((doy - 118) / 16.0) ** 2)) + rng.gamma(2.0, 2.5, doy.size)
   # Модель запаздывает на двое суток и срезает пик
   q_sim = np.clip(0.88 * np.roll(q_obs, 2) + 3 + rng.normal(0, 5, doy.size), 0.1, None)

.. testcode::

   result = hm.kge_2012(q_obs, q_sim)
   print(f"kge_2012 = {float(result):.4f}")

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   kge_2012 = 0.9063

Независимый пересчёт по трёхчленной формуле даёт то же значение; слагаемого :math:`\alpha` в ней нет.

.. testcode::

   r = np.corrcoef(q_obs, q_sim)[0, 1]
   beta = q_sim.mean() / q_obs.mean()
   gamma = (q_sim.std(ddof=1) / q_sim.mean()) / (q_obs.std(ddof=1) / q_obs.mean())
   by_hand = 1 - np.sqrt((r - 1)**2 + (beta - 1)**2 + (gamma - 1)**2)
   print(f"{by_hand:.4f}")

.. testoutput::
   :options: +NORMALIZE_WHITESPACE

   0.9063

Компоненты показывают, где потеряна точность: фаза и форма в :math:`r`, объём в :math:`\beta`, амплитуда в :math:`\gamma`.

.. testcode::

   print({name: round(float(value), 3) for name, value in parts.items()})

   {'r': 0.981, 'alpha': 0.886, 'beta': 0.97, 'gamma': 0.913}

Особенности применения в гидрологии
-------------------------------------

Разложение помогает увидеть причину низкой оценки: ошибку фазы и формы гидрографа в :math:`r`, ошибку объёма в :math:`\beta`, ошибку амплитуды и изменчивости в :math:`\gamma`. Для этого сами компоненты полезнее итогового числа.

Mizukami et al. :footcite:p:`mizukami2019` сообщают, что калибровка по KGE (форма 2009 г.) воспроизводит годовые максимумы стока лучше, чем калибровка по NSE. Для формы 2012 г. этот вывод в прочитанной статье не проверялся.

Применять KGE′ к логарифмам расходов следует осторожно: Santos et al. :footcite:p:`santos2018` сообщают, что влияние константы, добавляемой к расходам, в этом случае меняется хаотично и не показывает тренда. В библиотеке этот случай отдельно не обрабатывается.
